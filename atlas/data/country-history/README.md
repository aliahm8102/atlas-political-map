# اطلاعات سالانهٔ کشورها

برای هر یک از ۱۸۳ کشور/قلمرو موجود در فهرست سایت، یک فایل JSON با کد ثابت آن کشور وجود دارد؛ برای نمونه `276.json` مربوط به آلمان و `364.json` مربوط به ایران است. نام‌های فارسی و انگلیسی کشور و مختصات در `../country-profiles.json` نگهداری می‌شوند. اطلاعات متغیر هر کشور را در همین پوشه و در فایل خودش ویرایش کنید.

داده‌های قبلی، طبق درخواست، به عنوان نقطهٔ شروع در کلید `2025` قرار گرفته‌اند. این انتقال به معنی تأیید آماری مقادیر برای سال ۲۰۲۵ نیست؛ سال مشاهدهٔ بعضی منابع قدیمی مشخص نبوده است. پایتخت‌هایی که قبلاً ترجمهٔ فارسی نداشتند، در `capitalFa` مقدار `null` دارند تا متن انگلیسی در رابط فارسی نمایش داده نشود. بقیهٔ سال‌ها هنوز وارد نشده‌اند.

## اضافه کردن یک سال

فایل کشور را باز کنید و داخل `years` یک کلید سال میلادی با ارقام انگلیسی اضافه کنید. ساختار هر سال باید هر پنج فیلد زیر را داشته باشد؛ مقدار نامشخص را `null` بگذارید. مثلاً شکل یک رکورد کامل برای آلمان این است:

```json
"2025": {
  "capitalFa": "برلین",
  "capitalEn": "Berlin",
  "areaKm2": 357022,
  "population": 83491249,
  "flagPath": "/flags/de.svg"
}
```

- `capitalFa`: فقط نام فارسی پایتخت. اگر ترجمه را نمی‌دانید `null` بگذارید.
- `capitalEn`: نام انگلیسی پایتخت.
- `areaKm2`: مساحت بر حسب کیلومتر مربع؛ عدد بدون کوتیشن و بدون ویرگول هزارگان. اعشار مجاز است، مانند `0.49`.
- `population`: جمعیت به صورت عدد صحیح نامنفی، بدون کوتیشن و جداکننده.
- `flagPath`: مسیر فایل پرچم از ریشهٔ `public`؛ مثلاً فایل `public/flags/history/de-1990.svg` با مسیر `/flags/history/de-1990.svg` ثبت می‌شود. پوشه‌های لازم را بسازید. SVG، PNG، WebP، JPG و GIF مجازند. فایل سال قبلی را برای عوض کردن پرچم یک سال دیگر بازنویسی نکنید؛ فایل جدا بسازید.

کلیدهای سال را با کاما از هم جدا کنید. می‌توانید با کپی کردن بلوک یک سال، سال دیگری بسازید و مقادیرش را تغییر دهید. ترتیب سال‌ها در فایل اهمیتی ندارد. از کامنت و ویرگول اضافه بعد از آخرین فیلد استفاده نکنید؛ JSON استاندارد است.

**سایت فقط رکورد همان سالِ انتخاب‌شده در خط زمان را نمایش می‌دهد.** اگر یک سال وجود نداشته باشد، تمام اطلاعات متغیر آن سال ناموجود نمایش داده می‌شود و پرچمی نشان داده نمی‌شود. مقدار `null` نیز فقط همان فیلد را ناموجود می‌کند. سایت از سال‌های قبل یا بعد داده قرض نمی‌گیرد و بین جمعیت‌ها میان‌یابی نمی‌کند. نام کشور همچنان با زبان فعال سایت نمایش داده می‌شود.

## استفاده از الگو و بررسی خطاها

فایل [template.json](./template.json) یک رکورد خالی دارد. برای افزودن سال به کشور موجود، بلوک داخل `years` را از آن کپی کنید. برای ساخت فایل تازه، کل فایل را کپی کنید، کد داخل `code` و نام فایل را هماهنگ کنید. کد باید در فهرست `../country-profiles.json` هم تعریف شده باشد؛ افزودن کشور تاریخی و مرزهایش کار جداگانه‌ای است.

فایل `schema.json` به ویرایشگرهایی مثل VS Code کمک می‌کند خطاهای ساختاری را نشان دهند. در زمان ساخت سایت نیز فایل‌ها اعتبارسنجی می‌شوند. پس از افزودن یا حذف فایل کشور، از پوشهٔ `atlas` دستور زیر را اجرا کنید؛ برای تغییر مقادیر یا افزودن سال در فایل موجود، اجرای این دستور لازم نیست:

```bash
npm run data:index-countries
```

فایل `index.ts` خودکار ساخته می‌شود و نباید دستی ویرایش شود. `template.json` و `schema.json` وارد اطلاعات سایت نمی‌شوند. برای بررسی کل داده‌ها، با Node 22 اجرا کنید:

```bash
node --experimental-strip-types --test scripts/country-profiles.test.mjs scripts/country-history.test.mjs
```

تغییر فایل‌های موجود در محیط توسعه با بارگذاری مجدد دیده می‌شود؛ نسخهٔ منتشرشده به build و انتشار مجدد نیاز دارد. اسکریپت `scripts/import-country-profiles.mjs` دادهٔ سالانهٔ موجود را بازنویسی نمی‌کند.
